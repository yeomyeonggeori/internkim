## Default Permission

Lets the web app hand the attendance widget its token, and see whether iOS lets it refresh in the background

#### This default permission set includes the following:

- `allow-install`
- `allow-supply`
- `allow-forget`
- `allow-background-refresh-state`
- `allow-open-settings`
