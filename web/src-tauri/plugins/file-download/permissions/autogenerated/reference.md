## Default Permission

Lets the web app ask the phone to download a file from its address, reporting progress, and keep it for the gallery or the share sheet

#### This default permission set includes the following:

- `allow-download`

## Permission Table

<table>
<tr>

<th>Description</th>
</tr>


<tr>

</td>

</td>
</tr>

<tr>
