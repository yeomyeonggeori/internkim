## Default Permission

Lets the web app register the phone's lock screen attendance tokens and close the lock screen card

#### This default permission set includes the following:

- `allow-register-listener`
- `allow-remove-listener`
- `allow-watch-tokens`
- `allow-held-tokens`
- `allow-lock-screen-state`
- `allow-close-cards`
