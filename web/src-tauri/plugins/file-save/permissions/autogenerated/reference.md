## Default Permission

Lets the web app save a downloaded file on this device without leaving the page

#### This default permission set includes the following:

- `allow-save`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`file-save:allow-save`

</td>
<td>

Enables the save command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`file-save:deny-save`

</td>
<td>

Denies the save command without any pre-configured scope.

</td>
</tr>
</table>
