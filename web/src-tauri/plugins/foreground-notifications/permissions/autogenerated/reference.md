## Default Permission

Lets the web app keep the open conversation's notifications from showing while it is on screen

#### This default permission set includes the following:

- `allow-hold-back`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`foreground-notifications:allow-hold-back`

</td>
<td>

</td>
</tr>

<tr>
<td>

`foreground-notifications:deny-hold-back`

</td>

</tr>
