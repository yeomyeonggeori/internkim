## Default Permission

Lets the web app hand a page to the system print sheet, where it can be printed or saved as a PDF

#### This default permission set includes the following:

- `allow-present`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`print-sheet:allow-present`

</td>
<td>

</td>
</tr>

<tr>
<td>

`print-sheet:deny-present`

</td>

</td>
</tr>
