## Default Permission

Lets the web app hold this computer's desktop-control switch and run the agent-desktop commands it allows, once the person has agreed in a native dialog

#### This default permission set includes the following:

- `allow-state`
- `allow-allow`
- `allow-ask-once`
- `allow-disallow`
- `allow-run`
- `allow-open-permission-guide`
