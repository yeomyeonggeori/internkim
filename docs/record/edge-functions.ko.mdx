웹 앱이 아니라 Supabase에서 실행됩니다. `verify_jwt`가 false인 함수는 인증 없는 요청에 답하므로, 누구를 허용할지는 그 함수의 본문이 정합니다.

| 이름 | JWT 검증 |
| --- | --- |
| `announce-attendance` | true |
| `announce-event-reminder` | false |
| `announce-task` | true |
| `notify` | false |
| `notify-test` | true |
| `setup-digest-key` | true |
| `setup-vapid` | true |
| `tell-member` | false |
