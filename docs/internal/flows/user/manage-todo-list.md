# Manage Todo List

## 목적

업무 투두를 만들고, 상태를 관리하고, 다른 사람에게 처리 요청도 한다.

## 유저가 하는 일

1. 자기 할 일을 직접 추가한다.
2. 동료에게 이 업무를 맡아달라고 요청할 수 있다.
3. 담당자를 따로 고르지 않으면 기본 담당자는 본인이다.
4. 필요하면 여러 명이 동시에 같은 업무를 함께 맡을 수 있다.
5. 상태를 `요청`, `예정`, `일시정지`, `중단`, `진행`, `완료`, `기각` 중 하나로 관리한다.
6. 변경 이력이나 현재 상태를 확인한다.

## 결과

- 업무 단위의 요청과 진행 상태가 추적된다.
- 자기 할 일과 동료에게 요청한 일이 같은 흐름 안에서 관리된다.
- 한 개의 task에 한 명 또는 여러 명이 함께 연결될 수 있다.
- 담당자를 지정하지 않은 개인 할 일은 기본적으로 본인 업무로 생성된다.
