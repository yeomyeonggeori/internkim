# Request Research

## 목적

유저가 원하는 규모에 맞춰 자료 조사를 하고, 신뢰 가능한 원문 출처를 명확히 밝힌 결과를 받는다.

## 유저가 하는 일

1. 조사 주제와 목적을 설명한다.
2. 원하는 조사 규모를 정한다.
3. 조사 결과에서 특히 보고 싶은 쟁점이나 질문을 알려준다.
4. 결과로 요약본과 조사 전문을 확인한다.

## 조사 원칙

- 유저가 요청한 범위와 깊이에 맞춰 조사한다.
- 원문 출처를 반드시 명시한다.
- 신뢰도 있는 출처만 사용한다.
- 기관, 공식 문서, 논문, 공신력 있는 매체 같은 1차 또는 신뢰 가능한 출처를 우선한다.
- 개인 웹사이트나 개인 블로그는 출처로 사용하지 않는다.

## 결과

- 조사 요약본이 제공된다.
- 조사 전문이 제공된다.
- 두 결과물은 구글독스 형태로 정리된다.
- 각 주장이나 핵심 정보에 대응하는 원문 출처를 확인할 수 있다.
