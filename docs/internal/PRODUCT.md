# Product

## Register

product

## Users

Employees use the company messenger and web application to complete company
work. They need an assistant that can recover useful context while respecting
each person's access to conversations and company records.

## Product Purpose

The assistant performs work through existing company tools. Its user.json
profile carries the broad user context. Memory carries selected useful facts
and decisions that the assistant can search, update, and delete when needed.

## Brand Personality

Calm, precise, approachable. Follow the shared interface described in DESIGN.md.

## Anti-references

Avoid decorative metric dashboards, graph-first navigation, and interfaces
that present conversation volume as evidence of reliable recall.

## Design Principles

- Show the remembered statement before storage details.
- Explain where information came from and who can access it.
- Keep profile, live company records, conversation history, and memory distinct.
- Make search, correction, and deletion produce observable results.
- Report unavailable or incomplete retrieval without inventing certainty.

## Accessibility & Inclusion

Use the existing Korean and English localization, semantic light and dark
tokens, labelled controls, keyboard access, and reduced-motion behavior.
