# Internal documents

Nothing here is published. `docs/` is what a docs site would serve, and this
directory is what stays with us.

The split is by audience. A document belongs here when it was written for
whoever is building the thing: commercial positioning, competitor comparisons,
designs that have not shipped, a customer's own migration, and the runbooks for
hardware we are retiring.

A document added anywhere in `docs/` starts here. Moving one up is a `git mv`
and a read: check that it says what a stranger needs, that it names no customer
and no person, and that the prose rules in `AGENTS.md` hold.
