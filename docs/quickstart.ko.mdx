이 문서는 호스팅된 김인턴을 쓰는 회사의 시작 순서입니다. 호스팅된
Supabase 중앙 평면과 웹 앱 뒤의 Cloudflare 서비스는 김인턴이 제공합니다.
회사는 전원이 켜져 있고 잠들지 않는 컴퓨터 한 대를 준비합니다. 이 컴퓨터는
바깥으로 연결하기만 하므로, 들어오는 포트나 DNS 레코드, Cloudflare 계정은
필요하지 않습니다.

## 시작 전에

다음을 준비하세요.

- 첫 관리자가 사용할 이메일 주소
- 전원이 켜져 있고 잠들지 않으며 인터넷에 연결된 컴퓨터
- Linux 컨테이너를 쓰는 Docker와 Docker Compose. macOS는 [Docker Desktop
  설치 안내](https://docs.docker.com/desktop/setup/install/mac-install/), Ubuntu는
  [Docker Engine 설치 안내](https://docs.docker.com/engine/install/ubuntu/)를
  보세요.
- Git과 Python 3
- 에이전트가 사용할 [OpenRouter API 키](https://openrouter.ai/settings/keys)

설치 프로그램은 Docker Compose와 Docker가 Linux 컨테이너로 실행되는지를
확인합니다. OpenRouter 키는 회사 컴퓨터에서 숨겨진 입력으로 받습니다.
직원 컴퓨터에는 아무것도 설치하지 않습니다.

## 1. 회사 만들기

[회사 시작 페이지](https://intern.kim/auth/claim?new-company=1)를 열고
첫 관리자의 이메일 주소를 입력하세요. 이메일로 받은 일회용 코드를 입력하고
비밀번호를 정한 다음 패스키를 등록하거나 건너뛰세요. 그 다음 회사 만들기
화면에서 회사 이름과 주소를 입력하고, 선택 사항인 초대 칸은 일단 비워 두세요.

![샘플 관리자 주소를 넣은 한국어 회사 시작 화면](/images/quickstart/signup-ko.png)

주소는 웹 앱에서 회사를 구분하는 경로가 됩니다. 로그인은
`https://intern.kim/<회사-주소>`에서 합니다. 호스트를 연결한 뒤 설정
화면에서 사람을 초대하면 임시 비밀번호를 확인할 수 있습니다.

![샘플 값이 들어간 한국어 회사 만들기 화면](/images/quickstart/company-ko.png)

## 2. 회사 연결 파일 받기

`https://intern.kim/<회사-주소>/settings/setup`을 여세요.
**연결 파일 받기**를 눌러 `internkim-host.json`을 회사 서버로 쓸 컴퓨터에
저장하세요. 이 파일에는 이 회사의 연결 키가 들어 있으므로 그 컴퓨터에만
보관하고, 커밋하거나 채팅으로 보내지 마세요.

설정 화면에는 실행할 명령도 나오고, 나중에는 **연결 확인**도 나타납니다.

![로컬 연결 확인이 성공한 한국어 회사 설정 화면](/images/quickstart/setup-ko.png)

## 3. 회사 서버 설치하기

회사 컴퓨터에서 설치 프로그램을 내려받아 연결 파일과 함께 실행하세요.

```bash
curl -fsSL https://intern.kim/install.sh | sh -s -- host
internkim-host install ~/Downloads/internkim-host.json
```

내려받기 스크립트는 이 컴퓨터에 맞는 빌드를 골라 공개된 `SHA256SUMS`와
대조한 뒤 `internkim-host`를 `~/.local/bin`에 놓습니다. 체크섬이 맞지 않으면
거부하고 아무것도 설치하지 않습니다.

`internkim-host install`은 연결 파일을 확인하고 OpenRouter 키를 먼저 묻습니다.
그 뒤 Docker Compose로 회사 서버를 시작합니다. `compose.yaml`, `01-buzz.sql`,
`compose.env`와 비밀 키는 `~/.internkim/companies/<company-id>` 아래에
저장됩니다. 다시 실행해도 이미 만들어 둔 키는 그대로 둡니다. 끝나면 출력된
`/settings/setup` 주소를 열어 **연결 확인**을 누르세요.

회사 서버와 컴퓨터에 저장되는 로컬 데이터는 이 컴퓨터에 남습니다. Docker를
실행한 채로 두고 컴퓨터가 잠들지 않게 하세요. Docker가 다시 시작하면
Docker가 서버도 다시 시작합니다.

상태 확인과 잠시 멈추거나 다시 시작할 때는 설치 디렉터리에서 실행하세요.

```bash
cd ~/.internkim/companies/<company-id>
docker compose --env-file compose.env ps
docker compose --env-file compose.env logs --follow
docker compose --env-file compose.env stop
docker compose --env-file compose.env start
```

그 디렉터리의 `compose.yaml`을 Docker Compose가 자동으로 찾습니다. `stop`과
`start`는 볼륨을 유지하므로, 잠시 멈출 때 디렉터리나 볼륨을 지우지 마세요.

## 4. 사람을 초대하고 첫 메시지 보내기

연결 확인이 성공한 뒤 `/<회사-주소>/settings/setup`의 초대 영역에서 사람을
추가하세요. 초대할 때마다 임시 비밀번호가 화면에 한 번 표시되고 메일은
가지 않습니다. `https://intern.kim/<회사-주소>`와 그 비밀번호를
당사자에게 직접 전달하세요. 당사자는 로그인한 뒤 비밀번호를 바꾸고 패스키를
등록할 수 있습니다.

![샘플 값이 들어간 한국어 구성원 초대 화면](/images/quickstart/invite-ko.png)

설정 화면에서 메신저를 열고 에이전트에게 첫 부탁을 보내세요. 예를 들면:

> 내 업무에 설치 확인을 등록해줘.

메시지 아래 답글을 열면 처리 결과를 볼 수 있습니다. **업무**에서도 새 업무를
확인하세요.

![설치 확인 업무를 등록한 뒤 김인턴이 보낸 답글](/images/quickstart/messenger-ko.png)

에이전트는 설치 때 입력한 OpenRouter 키를 사용합니다. 사람들은 서버를 각자
설치하지 않고 호스팅된 웹 앱과 회사 메신저를 사용합니다.

## 컴퓨터를 바꿀 때

연결 파일은 회사에 묶여 있습니다. 기존 연결을 바꿔야 할 때는
`https://intern.kim/<회사-주소>/settings/setup`에서 새 파일을 받은 뒤
새 컴퓨터에 적용하세요. 연결 파일만 옮겨서는 호스트 데이터가 따라가지
않습니다. 로컬 에이전트, 메신저, 미디어 데이터도 옮겨야 한다면 비공개 설치
디렉터리와 Docker 볼륨을 먼저 백업하세요. 호스팅된 회사와 구성원 계정은
남지만, 이전 연결 파일은 교체 뒤 작동하지 않습니다.
