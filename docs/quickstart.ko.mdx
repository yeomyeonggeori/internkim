이 문서는 호스팅된 김인턴을 쓰는 회사의 시작 순서입니다. 김인턴은 웹 앱과 중앙
서비스를 제공합니다. 회사는 인터넷에 연결되고 계속 켜져 있을 컴퓨터 한 대를
준비합니다. 호스트는 바깥으로 연결하기만 하므로 공개 주소나 들어오는 포트가
필요하지 않습니다.

## 시작 전에

다음을 준비하세요.

- 첫 관리자가 사용할 이메일 주소
- arm64의 Debian 13, Ubuntu 22.04 또는 24.04, Fedora, RHEL 호환 10(Rocky, AlmaLinux), Arch Linux, 혹은 Homebrew를 설치한 macOS 컴퓨터. 인터넷에
  연결하고 계속 켜 두어야 합니다.
- 회사 컴퓨터에 패키지를 설치할 관리자 권한
- 에이전트가 사용할 [OpenRouter API 키](https://openrouter.ai/settings/keys)

설치 중 회사 컴퓨터에서 OpenRouter API 키를 입력합니다. 터미널은 입력한 문자를
화면에 표시하지 않습니다. 직원들은 회사 컴퓨터에 호스트를 설치하지 않고 웹 앱을
사용합니다.

<Step>

## 회사 만들기 [#1-회사-만들기]

[회사 시작 페이지](https://intern.kim/auth/claim?new-company=1)를 열고
첫 관리자의 이메일 주소를 입력하세요. 이메일로 받은 일회용 코드를 입력하고
비밀번호를 정한 다음 패스키를 등록하거나 건너뛰세요. 그 다음 회사 만들기
화면에서 회사 이름과 주소를 입력하고, 선택 사항인 초대 칸은 일단 비워 두세요.

![샘플 관리자 주소를 넣은 한국어 회사 시작 화면](/images/quickstart/signup-ko.png)

주소는 웹 앱에서 회사를 구분하는 경로가 됩니다. 로그인은
`https://intern.kim/<회사-주소>`에서 합니다. 호스트를 연결한 뒤 설정
화면에서 사람을 초대하면 임시 비밀번호를 확인할 수 있습니다.

![샘플 값이 들어간 한국어 회사 만들기 화면](/images/quickstart/company-ko.png)

</Step>

<Step>

## 회사 연결 파일 받기 [#2-회사-연결-파일-받기]

`https://intern.kim/<회사-주소>/settings/setup`을 여세요.
`연결 파일 받기`를 눌러 `internkim-host.json`을 회사 서버로 쓸 컴퓨터에
저장하세요. 이 파일에는 컴퓨터를 이 회사에 연결하는 키가 들어 있으므로 그
컴퓨터에만 보관하고, 커밋하거나 채팅으로 보내지 마세요. Linux에서는 설치가 이
키를 한 번 쓰고 없앱니다. 그 뒤로 컴퓨터는 자기 키로 로그인하고, 파일로는 다른
컴퓨터를 연결할 수 없습니다.

설치 뒤 설정 화면에 `연결 확인`이 나타납니다.

![로컬 연결 확인이 성공한 한국어 회사 설정 화면](/images/quickstart/setup-ko.png)

</Step>

<Step>

## 회사 서버 설치하기 [#3-회사-서버-설치하기]

회사 컴퓨터에서 설치 프로그램을 실행한 다음 연결 파일을 적용하세요. 첫 명령은
Linux에서 apt, dnf 또는 pacman 패키지를, macOS에서 Homebrew 패키지를 설치합니다. 둘째 명령은
호스트 서비스를 등록하고 OpenRouter 키를 묻습니다.

```bash
curl -fsSL https://intern.kim/install.sh | sh -s -- host
sudo internkim install ~/Downloads/internkim-host.json
```

설치 프로그램은 컴퓨터의 서비스 관리자를 통해 호스트를 실행하고, 컴퓨터가
다시 켜지면 자동으로 시작합니다. 컴퓨터가 잠들지 않게 하세요. 설치가 끝나면
출력된 `/settings/setup` 주소에서 `연결 확인`을 누르세요. 서비스 상태와 로그는
[호스트 운영 안내](/ko/running-the-host)를 보세요.

</Step>

<Step>

## 사람을 초대하고 첫 메시지 보내기 [#4-사람을-초대하고-첫-메시지-보내기]

연결 확인이 성공한 뒤 `/<회사-주소>/settings/setup`의 초대 영역에서 사람을
추가하세요. 초대할 때마다 임시 비밀번호가 화면에 한 번 표시되고 메일은
가지 않습니다. `https://intern.kim/<회사-주소>`와 그 비밀번호를
당사자에게 직접 전달하세요. 당사자는 로그인한 뒤 비밀번호를 바꾸고 패스키를
등록할 수 있습니다.

![샘플 값이 들어간 한국어 구성원 초대 화면](/images/quickstart/invite-ko.png)

설정 화면에서 메신저를 열고 에이전트에게 첫 부탁을 보내세요. 예를 들면:

> 내 업무에 설치 확인을 등록해줘.

메시지 아래 답글을 열면 처리 결과를 볼 수 있습니다. `업무`에서도 새 업무를
확인하세요.

![설치 확인 업무를 등록한 뒤 김인턴이 보낸 답글](/images/quickstart/messenger-ko.png)

에이전트는 설치 때 입력한 OpenRouter 키를 사용합니다. 사람들은 서버를 각자
설치하지 않고 호스팅된 웹 앱과 회사 메신저를 사용합니다.

## 컴퓨터를 바꿀 때

연결 파일은 회사에 묶여 있습니다. 기존 연결을 바꿔야 할 때는
`https://intern.kim/<회사-주소>/settings/setup`에서 새 파일을 받은 뒤
새 컴퓨터에 적용하세요. 연결 파일만 옮겨서는 호스트 데이터가 따라가지
않습니다. 로컬 에이전트, 메신저, 미디어 데이터도 옮겨야 한다면
[호스트에 저장되는 데이터](/ko/what-lives-where)를 먼저 백업하세요.
호스팅된 회사와 구성원 계정은 남지만, 이전 연결 파일은 교체 뒤 작동하지 않습니다.
