# Add Calendar Event

## 목적

구글 캘린더에 일정이나 휴가 일정을 추가한다.

## 유저가 하는 일

1. 일정 또는 휴가의 제목, 날짜, 시간, 장소, 참석자나 메모를 전달한다.
2. 휴가라면 종일 일정인지, 반차인지 같은 형태를 함께 알려준다.
3. 필요하면 반복 여부를 함께 알려준다.
4. 생성된 일정을 확인한다.

## 결과

- 구글 캘린더에 새 일정이 생성된다.
- 휴가도 같은 방식으로 캘린더 일정으로 기록된다.
- 일정 장소 정보도 함께 저장된다.
- 사용자가 미리 설정해둔 선호 시간, 준비 시간, 이동 시간을 기준으로 아침 알림 계산에 반영된다.
