회사 호스트는 arm64 또는 amd64의 Debian 13, Ubuntu 22.04 또는 24.04, 혹은 Homebrew를 설치한 macOS에서 실행됩니다. 인터넷에
연결하고 계속 켜 두어야 합니다. 설치 프로그램은 Debian·Ubuntu의 systemd나 macOS의
launchd에 서비스를 등록합니다. 공개 주소, 외부에서 들어오는 포트, Docker 설치는
필요하지 않습니다.

## 설치하기

회사 설정 화면에서 연결 파일을 받은 다음 실행하세요.

```bash
curl -fsSL https://intern.kim/install.sh | sh -s -- host
sudo internkim install ~/Downloads/internkim-host.json
```

첫 명령은 apt 또는 Homebrew 패키지를 설치합니다. 둘째 명령은 회사를 설정하고
OpenRouter API 키를 받은 뒤 호스트 서비스를 등록합니다. 컴퓨터가 켜지면
서비스가 자동으로 시작하고, 서비스가 종료되면 다시 시작합니다. 설치가 끝나면
화면에 나온 회사 설정 주소에서 연결 확인을 누르세요.

## 서비스 확인하기

Debian과 Ubuntu에서는 systemd에서 상태와 로그를 확인합니다.

```bash
systemctl list-units 'internkim*' 'blueclaw*' 'buzz*'
systemctl status internkim-relay
journalctl -u internkim-relay -n 50 --no-pager
```

macOS에서는 `launchctl print system/kim.intern.<service>`로 서비스를 확인합니다.
로그는 `/var/log/internkim/`에 있습니다.

## 설정

설치 프로그램은 회사 연결 정보와 생성된 자격증명을 접근이 제한된 호스트 데이터
디렉터리에 저장합니다. 대부분은 이 파일을 직접 고칠 필요가 없습니다. 선택 설정은
`/etc/internkim/company-host.env`에 둡니다. 지원하는 변수와 기본값은 생성된
[호스트 설정 참조](https://github.com/yeomyeonggeori/internkim/blob/main/host/README.md)에
있습니다. API 키와 연결 파일은 설정 파일에 넣지 마세요.

## 로컬 데이터

회사 컴퓨터에는 에이전트의 대화와 업무 이력, 기억, 워크스페이스 파일, 전달 대기
메시지가 저장됩니다. 호스팅된 회사 기록과는 별개입니다. 호스트를 백업하거나
교체하기 전에 [무엇이 어디 사는지](/ko/what-lives-where) 확인하세요.

## 답 크기

전송 한도를 넘는 답에는 릴레이가 바이트 수와 함께 `413`으로 응답합니다. 기본
상한은 3,000,000바이트이며 `ANSWER_BYTE_CEILING`으로 바꿀 수 있습니다. 0 이하의
값은 호스트 시작을 막습니다. 프로필 사진 한도는 base64 인코딩으로 크기가
늘어나는 만큼 이 상한에서 계산합니다.

## 네트워크 연결

호스트는 바깥으로 연결하고 로컬 인터페이스에서만 요청을 받습니다. 컴퓨터 관리는
같은 네트워크의 셸이나 회사가 관리하는 원격 접속 방법을 사용하세요.
