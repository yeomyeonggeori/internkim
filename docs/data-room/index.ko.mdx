---
title: 데이터룸
description: 서클로 읽고 링크로 공유하는 회사의 문서 보관소.
---

데이터룸은 회사의 자료입니다. 문서 정보와 파일은 중앙 기록과 파일
저장소에 보관하며, 블루클로는 요청자의 권한으로 접근합니다.
에이전트 컴퓨터를 교체해도 자료는 유지됩니다.

분류는 문서의 업무 목적을 기준으로 대분류와 중분류까지만 사용합니다.
의미 기반 문자 코드가 분류를 식별하며, 이름과 표시 순서는 바꿀 수 있습니다.
분류가 모호한 자료는 `X-inbox`에 보관합니다.

파일 → 데이터룸에서 보관된 자료를 조회합니다. 링크 공유에서 서클,
유효 기간과 원본 다운로드 허용 여부를 선택하세요. 링크와 6자리 코드를
수신자에게 전달하면, 수신자는 계정 없이 코드를 입력하고 기밀유지 안내에
동의하여 자료를 엽니다. 구성원이 속할 서클과 서클 편집은 설정 → 회사에서
관리합니다.

문서 사이트를 배포해도 회사의 데이터룸 기능은 바뀌지 않습니다.
DB 마이그레이션을 적용하고 호환되는 회사 런타임·플러그인·웹/API를 함께
배포해야 합니다. 마이그레이션은 기존 회사에 기본 분류와 서클을 생성하며,
새 회사는 생성 시 기본 구성을 받습니다. 모든 자료는 분류에 담기며,
분류가 없는 자료는 올린 사람의 수신함으로 들어갑니다.
