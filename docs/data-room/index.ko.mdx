---
title: 데이터룸
description: 회사의 문서 보관소와 역할별 공유.
---

데이터룸은 회사의 자료입니다. 문서 정보와 파일은 중앙 기록과 파일
저장소에 보관하며, 블루클로는 요청자의 권한으로 접근합니다.
에이전트 컴퓨터를 교체해도 자료는 유지됩니다.

분류는 문서의 업무 목적을 기준으로 대분류와 중분류까지만 사용합니다.
의미 기반 문자 코드가 분류를 식별하며, 이름과 표시 순서는 바꿀 수 있습니다.
분류가 모호한 자료는 `X-inbox`에 보관합니다.

데이터룸에서 공유를 열어 이메일과 역할을 선택하면 초대를 이메일로 보냅니다.
초대 링크를 복사할 수도 있습니다.
수신자는 해당 이메일을 인증해 초대를 수락합니다. 역할 범위의 현재 자료와
이후 추가되는 자료를 읽을 수 있으며, 회사 구성원으로 등록되지 않습니다.
관리자는 접근 권한을 회수할 수 있습니다.

문서 사이트를 배포해도 회사의 데이터룸 기능은 바뀌지 않습니다.
DB 마이그레이션을 적용하고 호환되는 회사 런타임·플러그인·웹/API를 함께
배포해야 합니다. 마이그레이션은 기존 회사에 기본 분류와 역할을 생성하며,
새 회사는 생성 시 기본 구성을 받습니다. 기존 자료는 개별 재분류할 때까지
현재 clearance 접근 권한을 유지합니다.
