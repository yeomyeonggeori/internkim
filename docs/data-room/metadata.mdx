---
title: Document metadata
---

Each document has an identifier, title, kind, factual summary, language and
date. `categoryCode` names its intermediate category or `X`. Optional fields
include counterpart, covered period, tags, status and the document it supersedes.
A replacement preserves earlier documents.

`sha256` identifies the original bytes. `storagePath` identifies the original
in the private asset bucket. Derived `content.txt` provides its text preview.
The original remains unchanged; a standalone tree stores metadata in its
`<file>.md` sidecar and generates catalogs from those labels.

Write a summary that states the document's facts, amounts and dates. Review
extraction warnings when OCR, transcription or a format converter is unavailable.
A missing derivative does not change the document's permissions.
