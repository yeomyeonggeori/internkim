---
title: 에이전트 작업 흐름
---

자료를 넣을 때 텍스트를 추출하고 `company_document_classify`를 호출합니다.
jev 한 호출에 중분류를 절반씩 나눈 두 choice를 보내며 각각 `other`를 포함합니다.
템플릿에서 대분류별 의미 그룹을 지정하고 하위 중분류가 그 그룹을 따릅니다.
한쪽만 분류를 고르면 그 코드를 사용하고, 양쪽이 고르면 선택된 코드의
probability가 높은 쪽을 사용합니다. 둘 다 `other`거나 동률이면 `X`입니다. 반환된 코드와 해시로
원본과 `content.txt`를 올린 다음 문서 정보를 등록합니다.
등록 전 분류 파일은 조회할 수 없습니다.

자료를 찾을 때 분류별 목록이나 허용된 문서 검색을 사용합니다.
요약, 추출 텍스트, 원본 순으로 필요한 자료를 읽습니다.
요청자의 신원을 행·파일 접근 정책까지 전달합니다.

공유할 때 현재 역할과 권한을 확인한 다음 수신자에게 역할을 부여하고
초대 링크를 반환합니다. 커스텀 역할에는 대분류 또는 중분류 코드를
지정합니다. 기존 역할 수정과 중분류 추가 전에 영향을 받는 수신자를
확인합니다. 공개는 명시적인 발행 요청이 있어야 합니다.

dataroom 스킬이 이 흐름을 제공합니다. 내보내기 도구는 생성된 템플릿으로
폴더를 만들고 원본, 문서 정보와 목록을 보존합니다.
이전 구조로 내보낸 폴더는 의미를 검토해 재분류해야 합니다.
