title: 에이전트 작업 흐름
---

자료를 넣을 때 텍스트를 추출하고 `company_document_classify`를 호출합니다.
jev 한 호출에 하위 분류가 없는 분류를 두 그룹으로 나눈 choice를 보내며 각각 `other`를 포함합니다.
템플릿에서 대분류별 의미 그룹을 지정하고 하위 중분류가 그 그룹을 따릅니다.
한쪽만 분류를 고르면 그 코드를 사용하고, 양쪽이 고르면 선택된 코드의
probability가 높은 쪽을 사용합니다. 둘 다 `other`거나 동률이면 `X`입니다. 반환된 코드와 해시로
문서 정보를 등록한 다음, 원본을 원래 파일 이름으로 올리고 `content.txt`를 그
옆에 올립니다. 파일은 등록된 문서에 속하므로 경로에 그 문서가 들어갑니다.

| 단계 | 하는 일 |
|---|---|
| 분류 선택 | 문서의 업무 목적에 맞는 분류 코드 하나를 고릅니다. |
| 문서 정보 등록 | 제목·요약·분류 코드·해시를 문서 목록에 기록합니다. |
| 파일 업로드 | 원본과 추출 텍스트를 그 분류의 위치에 올립니다. |

저장은 파일 업로드와 문서 정보 등록을 합쳐 부르는 말이며, 별도 단계가 아닙니다.

자료를 찾을 때 분류별 목록이나 허용된 문서 검색을 사용합니다.
요약, 추출 텍스트, 원본 순으로 필요한 자료를 읽습니다.
요청자의 신원을 행·파일 접근 정책까지 전달합니다.

구성원은 자기 서클을 통해 읽으므로, 동료에게 접근을 주려면 서클에
넣습니다. 회사 밖과 공유할 때는 한 서클이 읽는 범위를 수신자의 이메일에
빌려주고 초대 링크를 반환합니다. 서클에는 대분류 또는 중분류 코드를
지정합니다. 서클 수정과 중분류 추가 전에 접근이 바뀌는 사람을 확인합니다.
공개는 명시적인 발행 요청이 있어야 합니다.

dataroom 스킬이 이 흐름을 제공합니다. 내보내기 도구는 생성된 템플릿으로
폴더를 만들고 원본, 문서 정보와 목록을 보존합니다.
이전 구조로 내보낸 폴더는 의미를 검토해 재분류해야 합니다.
