---
title: The data room
description: The company's document archive and role-based sharing.
---

The data room belongs to the company. Its metadata and files live in the
central record and asset store. Blueclaw accesses them as the requester.
Replacing the agent's computer preserves the archive.

Documents are filed by business function in a two-level taxonomy. Stable
mnemonic codes identify categories; names and display order can change.
An uncertain document waits in `X-inbox`. File formats and intended readers
do not determine its category.

Open Files → Dataroom to browse the archive. Share link lets you choose a
reader role, expiration and whether original downloads are allowed. Send the
link and its six digit code to the recipient. They enter the code and
acknowledge the confidentiality notice without creating an account.
Manage employee reader roles and custom roles in Settings → Company.

Updating this documentation does not update a company's data room. Apply the
database migrations and deploy compatible company runtime, plugin and web/API
versions together. Migrations initialize default categories and roles for
existing companies and new companies inherit them automatically. Existing
documents retain their clearance access until individually reclassified.

[Categories and defaults](/docs/data-room/layout) defines the template.
[Access and sharing](/docs/data-room/clearance) explains permissions.
[Metadata](/docs/data-room/metadata) describes the document record.
[Agent workflow](/docs/data-room/agent) explains filing and finding.
