  <h2 className="internkim-overview__section-title">왜 필요한가요</h2>

  <div className="internkim-overview__prose">

AI 채팅 도구는 똑똑하지만 우리 회사 일을 모릅니다. 누가 오늘 휴가인지, 어떤 계약이 진행 중인지, 지난주에 무엇을 약속했는지 매번 복사해서 알려 줘야 하고, 답을 받은 뒤 실제로 처리하는 일은 결국 사람이 합니다.

회사의 일은 근태 시스템, 캘린더, 메신저, 드라이브, 엑셀에 흩어져 있어서 AI가 이어서 처리할 수가 없습니다. 각 도구가 따로 붙인 AI 기능은 자기 도구 안의 일만 압니다.

김인턴은 일하는 공간과 AI를 같이 만들었습니다. 일이 한곳에 있으니 AI가 회사의 맥락을 알고, 부탁한 사람의 권한으로 직접 처리합니다. 권한과 데이터는 회사가 쥡니다.

</div>
